## 测量模块（ASIC）协作方式学习笔记（4G CRS / 5G SSB）

> 说明：本文为学习用途的**抽象化总结**。不包含任何截图中的专有实现细节、参数、门限或可用于还原具体芯片/产品的信息。框图为重新绘制的功能等价示意。

---

## 1. 总体视角：一条主解调链 + 多条并行测量/估计支路

这类接收机/测量 ASIC 通常可以分成两类并行协作的链路：

- **主解调链（为了“能解码/能出数据”）**：同步/信道估计 → 均衡 → MIMO 检测 → 软比特合并 → 解码  
- **测量链（为了“出 RSRP/RSRQ/RSSI/SINR 等指标”）**：在与主链共享的同一套时频资源上，基于已知参考信号做功率/质量统计

二者共享前端与频域资源栅格，因此可同时支持：

- **5G：基于 SSB（含波束/SSB index）**的测量
- **4G：基于 CRS（Cell-RS）**的测量

---

## 2. 功能模块分层（从输入到输出）

从“数据怎么走”角度，可把模块按功能分为 5 层：

### 2.1 前端与幅度控制（保证动态范围与可用性）

- **前端数字处理**：对 ADC 后的 IQ 做基础处理（抽象称“DFE/前端”）。
- **AGC/增益计算与补偿**：保证 FFT 前后的幅度范围合理，避免溢出或量化损失。

### 2.2 频域化与基础校正（形成时频栅格）

- **频移/去载波（NCO/混频）**：把信号搬移到合适的频率基带，减小残余频偏影响。
- **FFT**：把时域采样变为频域子载波资源栅格。
- **基础干扰/失配校正（TD/FD 校正）**：对时域/频域的已知失配或干扰做抑制/校正（抽象为“IC/校正”）。

### 2.3 同步/检测与信道估计（由“已知序列”驱动）

这部分的共同特征是：需要**已知参考信号**（例如：
- 5G：SSB 内的同步/广播相关参考、以及其他测量参考
- 4G：CRS（Cell-RS）
以及数据解调相关参考）

典型输出包括：

- **定时/频偏等同步参数**（用于后续均衡、以及保证测量口径一致）
- **原始信道估计（Raw CE）**与其平滑版本
- **“当前测量对象”的选择信息**（例如 5G SSB index/波束相关选择）

### 2.4 均衡、MIMO 与软信息链（主解调链）

- **均衡（MMSE 等）**：利用信道估计把频域符号“拉直”。
- **MIMO 检测/合并**：多天线/多层场景下恢复各层数据。
- **软比特合并（LLR combine）→ 解码**：输出最终比特/块解码结果。
- **噪声估计（NE）**：为均衡与软信息可靠度标定提供参数（影响误码与吞吐）。

### 2.5 测量输出链（RSRP/RSRQ/RSSI/SINR 等）

与主解调链并行，测量链通常包含：

- **RSSI 统计**：在配置的符号集合与带宽上做功率统计（口径可被高层配置改变）。
- **参考信号功率统计（用于 RSRP/RSRQ/SINR）**：基于参考信号所在 RE 的功率样本做统计并输出指标。
- **QCL/定时一致性估计**：保证跨参考/跨 SSB/跨波束测量对齐。
- **频偏/多普勒估计**：提升同步/测量稳定性，并可为质量估计提供辅助信息。

```mermaid
  D --> E[FFT/频域栅格]

  %% 主解调链
  I --> J[均衡(如MMSE)]
  J --> K[MIMO检测/合并]
  K --> L[软比特(LLR)合并]
  L --> M[解码器]
  F --> N[噪声估计NE]
  N --> J
  N --> L

  %% 并行测量链
  F --> R[RSSI统计]
  H --> P[参考信号功率统计(RSP)]

  G --> S[QCL/定时一致性估计]
  S --> Q
  N --> Q
```

读图方法：

- 左侧 `A~F` 是“共享前端 + 频域化资源栅格”，主链与测量链都从这里取数据。
- 中间 `G/H/I` 是“由已知参考驱动”的同步/信道估计与参数选择，既服务解调也服务测量。
- 右上 `J~M` 是主解调链；右下 `R/P/Q/S` 是测量链。

## 4. 4G（CRS）与 5G（SSB）测量的差异点（学习版）

### 4.1 共同点

- 都依赖“已知参考信号”来做信道估计与功率统计。
- 都在共享的频域资源栅格上进行统计，因而与前端/FFT/校正强相关。
- 都需要同步/定时的一致性保障，否则同一指标跨时刻不可比。

### 4.2 5G（基于 SSB）的典型特点

- 需要先完成 **SSB 相关检测与选择**（例如“哪个 SSB/波束更合适”）。
- 测量与波束管理强关联：同一小区不同 SSB/波束下测量结果可能差异明显。
- 更依赖“选择 + 平滑 + 一致性”来保证测量稳定性。

### 4.3 4G（基于 CRS）的典型特点

- CRS 分布相对固定，测量对象选择（“用哪个参考”）的复杂度通常低于 SSB 波束选择。
- 仍然需要处理多天线下的参考映射与统计口径（例如不同端口 RE 分布对统计的影响）。

---

## 5. 学习建议：读这张框图最该抓住的 3 件事

1. **共享栅格**：前端/FFT 产出的频域栅格是“所有事情的共同底座”。  
2. **已知参考驱动**：同步、信道估计、测量都围绕已知参考序列展开。  
3. **主链/测量链并行**：解码追求“正确恢复数据”，测量追求“稳定可比的统计口径”；二者共享很多模块但目标不同。
