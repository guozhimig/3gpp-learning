在数字信号处理里，**FIR（Finite Impulse Response，有限脉冲响应）**滤波器是最适合“从零写清数学、再落到一行代码”的入门对象：没有反馈环路，稳定性直观，且容易和卷积、频响、线性相位串成一条线。本文面向有编程与数学基础的读者，按「概念 → 频域 → 设计 → 相位 → 可运行 Demo → 易错点」组织；文末给出延伸阅读方向，正文不堆零散外链。

---

## 1. 整体认知：FIR 在做什么

一句话：**FIR 输出是当前与过去有限个输入的加权求和（离散卷积），权值就是滤波器系数。**

---

## 2. 概念与定义

### 2.1 差分方程与脉冲响应

输出 $y[n]$ 只依赖有限个过去输入：

$$
y[n] = \sum_{k=0}^{M-1} h[k]\, x[n-k]
$$

其中 $h[k]$ 为 FIR 系数，长度为 $M$（也常称阶数为 $M-1$ 或把 $M$ 叫抽头数，不同教材叫法略有出入，**以你使用的工具文档为准**）。

从运算形式上看，上式就是**离散线性卷积**：$y[n] = (h * x)[n]$。通信里「接收信号 = 发送符号与**信道冲激响应**卷积」也是同一类 **LTI（Linear Time-Invariant，线性时不变）** 系统的叠加式；差别在于**谁扮演 $h[\cdot]$**：滤波器里 $h[k]$ 是你按频域指标**设计**出来的系数，信道模型里 $h[k]$ 多指**物理多径/色散**造成的响应（再叠上你设计的均衡器时，又会出现新的等效冲激响应）。数学结构相同，物理对象不同。

若输入为单位脉冲 $\delta[n]$，则输出即为 $h[n]$，且 $n \ge M$ 后输出为 0，故称**有限**脉冲响应。无反馈时，**不存在 IIR 那种极点带来的不稳定问题**（工程上仍要注意系数量化、溢出，但稳定性概念上比 IIR 简单）。

### 2.2 FIR 与 IIR 的对比（学习用）

| 特性 | FIR | IIR |
|------|-----|-----|
| 稳定性 | 无反馈，BIBO 意义下稳定直观 | 有反馈，需关注极点位置 |
| 相位 | 易实现严格线性相位（系数对称时） | 相位通常非线性 |
| 代价 | 同等过渡带/阻带往往需更高阶（更多乘法） | 阶数往往更低 |

## 3. 频域直觉

### 3.1 滤波器即「选频」

- **低通**：衰减低频以上成分（或保留低频，依定义与归一化约定表述）
- **高通 / 带通 / 带阻**：在频域上选择不同频段

### 3.2 频率响应

离散时间 FIR 的频率响应（DTFT 形式）：

$$
H(e^{j\omega}) = \sum_{n=0}^{M-1} h[n]\, e^{-j\omega n}
$$

读法说明：上式不是「在时延 $n$ 处的频率响应」这种逐点定义，而是把**整条**冲激响应 $\{h[n]\}_{n=0}^{M-1}$ 通过 DTFT 合成**关于连续角频率 $\omega$ 的函数** $H(e^{j\omega})$。每一项 $h[n]e^{-j\omega n}$ 表示第 $n$ 个延迟抽头对频率 $\omega$ 的复增益贡献，**对所有 $n$ 求和**才得到系统在 $\omega$ 上的总响应。$h[n]$ 既可指 FIR 系数，也可指离散化后的信道冲激响应，公式相同。

工程上常看幅度 $|H(e^{j\omega})|$（dB）与相位 $\angle H(e^{j\omega})$，并区分通带、过渡带、阻带；**截止频率**是指标边界，具体定义与测量方式以设计工具为准。

## 4. 常见设计思路（知道名字即可跑通第一步）

### 4.1 窗函数法

理想频响 $\to$ 理想冲激响应（无限长）$\to$ **加窗截断**得到有限长 $h[n]$。直观、好实现；代价是主瓣/旁瓣与阶数之间的折中。

### 4.2 频率采样法

在频域若干点上指定 $H[k]$，再经逆 DFT 得到 $h[n]$；在采样点处可精确控制，但采样点之间需额外处理（学习阶段知道思路即可）。

### 4.3 最优化 / 最小二乘（如 `firls`）

在通带、阻带等频段上最小化与理想幅度的误差；适合「多段指标」场景，但依赖工具与数值优化。

## 5. 线性相位（FIR 最常考的一块）

### 5.1 线性相位的条件

FIR滤波器实现线性相位的充分必要条件是单位脉冲响应 $h[n]$ 满足对称性条件。根据对称性类型和滤波器长度，共有四种线性相位FIR类型：

| 类型 | 对称性 | 长度M | 群延迟 | 相位表达式 | 适用场景 |
|------|--------|-------|--------|------------|----------|
| I型 | 偶对称 | 奇数 | (M-1)/2 | $-\omega(M-1)/2$ | 低通、高通、带通、带阻 |
| II型 | 偶对称 | 偶数 | (M-1)/2 | $-\omega(M-1)/2$ | 低通、带通（不能实现高通）|
| III型 | 奇对称 | 奇数 | (M-1)/2 | $-\omega(M-1)/2 + \pi/2$ | 希尔伯特变换、微分器 |
| IV型 | 奇对称 | 偶数 | (M-1)/2 | $-\omega(M-1)/2 + \pi/2$ | 希尔伯特变换、微分器 |

### 5.2 对称性条件

**偶对称条件**：
$$h[n] = h[M-1-n], \quad 0 \le n \le M-1$$

**奇对称条件**：
$$h[n] = -h[M-1-n], \quad 0 \le n \le M-1$$

### 5.3 为什么「对称」会带来「常数群延迟」

**群延迟**定义为 $\tau_g(\omega) = -\dfrac{\mathrm{d}\phi(\omega)}{\mathrm{d}\omega}$，其中 $\phi(\omega)=\angle H(e^{j\omega})$ 为相位。若相位对 $\omega$ 是**仿射**的：$\phi(\omega) \approx -\tau\,\omega + \text{常数}$（在一段频带内），则 $\tau_g(\omega)=\tau$，与 $\omega$ 无关，即各频率分量「一起走」$\tau$ 个采样点的时延。

对称（或反对称）把冲激响应限制成**关于中心抽头镜像**，使得 $H(e^{j\omega})$ 可写成「**线性相位因子**」与「**实（或纯虚）幅度型因子**」的乘积。一类常见写法（以偶对称、长度 $M$ 为例，略去类型细分）可记为：

$$
H(e^{j\omega}) \approx e^{-j\omega (M-1)/2}\, A(\omega)
$$

其中 $A(\omega)$ 在通带内通常为实值（符号变化时可能叠 $\pi$ 相位跳变）。于是 $\phi(\omega) \approx -(M-1)\omega/2 + (0\text{ 或 }\pi)$，对 $\omega$ 求导得常数群延迟 $\tau_g \approx (M-1)/2$。**对称性保证的是「相位随频率线性变化」这一结构**；直观上，系统对每个频率只叠加一个**公共的线性相位斜坡**，各频点延迟一致，波形形状得以保持（再叠上公共时移）。

#### 5.3.1 什么是「仿射」？与对称性是什么关系？

**「仿射」是数学中的一个重要概念**，简单来说，仿射函数是指可以表示为线性函数加上常数的形式：

$$f(x) = ax + b$$

其中：
- $ax$ 是线性部分
- $b$ 是常数偏移

**线性函数**必须满足：
1. $f(x+y) = f(x) + f(y)$（可加性）
2. $f(cx) = cf(x)$（齐次性）

线性函数必须经过原点（$f(0)=0$），而仿射函数可以有一个截距（$f(0)=b$）。

**在相位响应中的应用**：
- **线性相位**：$\phi(\omega) = -\tau\omega$（经过原点）
- **仿射相位**：$\phi(\omega) = -\tau\omega + \beta$（有常数偏移）

其中$\beta$可以是0或$\pi$，这对应于幅度函数$A(\omega)$的符号变化。

**对称性与仿射相位的关系**：

FIR滤波器的对称性（或反对称性）保证了相位响应是仿射的。

**偶对称情况**：
$$h[n] = h[M-1-n]$$
频率响应：
$$H(e^{j\omega}) = e^{-j\omega(M-1)/2} \cdot A(\omega)$$
相位：
$$\phi(\omega) = -\frac{M-1}{2}\omega + (0 \text{ 或 } \pi)$$

**奇对称情况**：
$$h[n] = -h[M-1-n]$$
频率响应：
$$H(e^{j\omega}) = e^{-j\omega(M-1)/2} \cdot jA(\omega) = e^{-j\omega(M-1)/2 + j\pi/2} \cdot A(\omega)$$
相位：
$$\phi(\omega) = -\frac{M-1}{2}\omega + \frac{\pi}{2} + (0 \text{ 或 } \pi)$$

**为什么对称性导致仿射相位？**

直观理解：
1. **对称性**意味着滤波器对信号的响应在时间上是"对称"的
2. 这种对称性导致所有频率分量经历相同的延迟（群延迟为常数）
3. 相位随频率的变化是线性的，可能有一个常数偏移（仿射）

数学上，对称性使得频率响应可以分解为：
- **线性相位因子**：$e^{-j\omega(M-1)/2}$（提供常数群延迟）
- **实（或纯虚）幅度型因子**：$A(\omega)$或$jA(\omega)$（提供可能的$\pi$或$\pi/2$相位跳变）

**重要概念澄清**：

- **对称性**指的是**抽头（系数）的对称性**，更专业地说是指**单位脉冲响应的对称性**。当输入是单位脉冲$\delta[n]$时，FIR滤波器的输出就是$h[n]$，$h[n]$完全描述了滤波器的特性，滤波器的系数就是单位脉冲响应的采样值。

- **仿射**描述的是**相位响应的特性**，即相位$\phi(\omega)$随频率$\omega$的变化关系。

- **对称性是因，仿射相位是果**：抽头的对称性保证了相位响应是仿射的，从而实现了常数群延迟。

这种表述在数字信号处理教材和文献中是非常标准和专业的。

### 5.4 线性相位的物理意义

当FIR滤波器满足线性相位条件时，其频率响应可以表示为：

$$H(e^{j\omega}) = A(e^{j\omega}) e^{-j\alpha\omega + j\beta}$$

其中：
- $A(e^{j\omega})$ 是实函数（可正可负），表示幅度特性
- $\alpha = (M-1)/2$ 是群延迟，为常数
- $\beta$ 是附加相位（0或$\pi/2$）

这意味着：
1. **群延迟为常数**：所有频率分量都经历相同的延迟 $\alpha$，不会因为频率不同而产生不同的延迟
2. **相位是频率的线性函数**：相位响应 $\angle H(e^{j\omega}) = -\alpha\omega + \beta$ 是一条直线
3. **波形不失真**：输入信号通过滤波器后，各频率分量保持相对相位关系不变，只是整体延迟了 $\alpha$ 个采样点

### 5.5 工程应用注意事项

1. **群延迟补偿**：在实际系统中，如果需要与其他处理链路对齐，需要考虑FIR滤波器的群延迟 $(M-1)/2$ 个采样点

2. **类型选择**：
   - 需要高通滤波器时，只能选择I型（奇数长度偶对称）
   - 需要90°相移时（如希尔伯特变换），选择III型或IV型
   - 一般低通/带通应用，I型和II型均可

3. **零点位置**：
   - II型滤波器在 $\omega = \pi$ 处必有零点，因此不能实现高通
   - III型滤波器在 $\omega = 0$ 和 $\omega = \pi$ 处都有零点
   - IV型滤波器在 $\omega = 0$ 处有零点

## 6. 卷积的直观理解

FIR滤波器的核心操作是**离散卷积**。在理解卷积前，先明确两个重要概念：

- **离线卷积**：处理已存储的完整信号，x[0]是最早的采样点，h[0]对应最早时刻的系数
- **实时处理**：处理流式数据，h[0]对应最新采样点，h[M-1]对应最老的采样点

让我们通过一个简单例子理解：

输入序列 x[n] = [1, 2, 3, 4, 5]  （从左到右：最早 → 最新）
滤波器系数 h[n] = [0.5, 0.3, 0.2]

卷积过程（离线视角）：

```text
位置0: 1×0.5 = 0.5
位置1: 2×0.5 + 1×0.3 = 1.3
位置2: 3×0.5 + 2×0.3 + 1×0.2 = 2.3
位置3: 4×0.5 + 3×0.3 + 2×0.2 = 3.3
位置4: 5×0.5 + 4×0.3 + 3×0.2 = 4.3
位置5: 5×0.3 + 4×0.2 = 2.3
位置6: 5×0.2 = 1.0
```

输出: `[0.5, 1.3, 2.3, 3.3, 4.3, 2.3, 1.0]`

**实时处理视角**（以计算位置4为例）：

```text
当前时刻 n=4，最新采样点 x[4]=5

滑动窗口状态：
x[4] x[3] x[2]  （最新 → 最老）
 ↓    ↓    ↓
h[0] h[1] h[2]
0.5  0.3  0.2

计算：5×0.5 + 4×0.3 + 3×0.2 = 4.3
```

直观理解：
- **离线卷积**：滤波器系数从左向右滑动，与输入序列做加权求和
- **实时处理**：每个输出点都是当前窗口内"最新→最老"采样点与"h[0]→h[M-1]"的对应加权求和
- 这就是FIR滤波的本质：**当前输出 = 最新点×h[0] + 次新点×h[1] + ... + 最老点×h[M-1]**

## 7. 常见窗函数对比

| 窗函数类型 | 主瓣宽度 | 第一旁瓣衰减 | 特点 |
|-----------|---------|------------|------|
| 矩形窗 | 最窄 | -13 dB | 过渡带最窄，但阻带衰减差 |
| 汉明窗 | 中等 | -43 dB | 常用，综合性能好 |
| 汉宁窗 | 中等 | -31 dB | 旁瓣衰减较好 |
| 布莱克曼窗 | 较宽 | -58 dB | 阻带衰减好，但过渡带宽 |
| 凯泽窗 | 可调 | 可调 | 通过β参数灵活控制 |

选择建议：
- 需要窄过渡带：矩形窗
- 通用场景：汉明窗
- 高阻带衰减：布莱克曼窗或凯泽窗

## 8. 实际应用场景

### 8.1 通信系统中的FIR应用
1. **脉冲成形滤波器**：如升余弦滤波器，用于限制带宽并减少码间干扰
2. **信道均衡**：补偿信道引起的失真
3. **抗混叠滤波**：ADC前的抗混叠滤波的数字实现
4. **载波恢复**：提取载波频率分量

### 8.2 性能指标量化
- **过渡带宽度**：通常用归一化频率表示，如0.1π
- **阻带衰减**：通常要求≥40dB（汉明窗可达）
- **通带波纹**：通常要求≤0.1dB
- **群延迟**：线性相位FIR为(M-1)/2个样点

## 9. 可运行 Demo（MATLAB）

**目标**：合成含 10 Hz、50 Hz、200 Hz 的正弦与噪声，用**低通**尽量保留 10 Hz、削弱 50 Hz 与 200 Hz；对比 `firls`（最小二乘）与 `fir1`（窗函数法）两种系数，并观察频响与输出。

**环境**：MATLAB + Signal Processing Toolbox（提供 `fir1`、`firls`、`freqz`、`grpdelay`、`filter`）。

```matlab
%% FIR 滤波器学习 Demo（从零到可跑）
% 本脚本演示了两种FIR滤波器设计方法:
%   1. firls - 最小二乘法 (分段理想幅度逼近)
%   2. fir1  - 窗函数法 (汉明窗)
%
% 测试信号包含三个频率分量:
%   - 10 Hz (低频,期望被保留)
%   - 50 Hz (中频,期望被衰减)
%   - 200 Hz (高频,期望被大幅衰减)
%
% 滤波器指标:
%   - 截止频率: 30 Hz
%   - 抽头数 M: 31 (阶数 = 30)
%   - 采样率: 1000 Hz
%
% 输出: 6个子图展示滤波效果和滤波器特性

clear; clc; close all;

%% 采样与测试信号
fs = 1000;                 % 采样率 Hz (每秒采集1000个样本)
t_duration = 1;              % 信号持续时间 1 秒
t = (0:1/fs:t_duration-1/fs).';  % 时间向量: 从0到0.999秒,步长1/1000秒

%% 生成多频测试信号
% 包含三个频率分量:
% - f1 = 10 Hz (低频,期望被保留)
% - f2 = 50 Hz (中频,期望被衰减)
% - f3 = 200 Hz (高频,期望被大幅衰减)
f1 = 10; f2 = 50; f3 = 200;
x_clean = sin(2*pi*f1*t) + 0.8*sin(2*pi*f2*t) + 0.5*sin(2*pi*f3*t);

%% 添加高斯白噪声
% randn 生成标准正态分布 N(0,1)
% 0.3 是噪声的标准差(幅度)
% size(x_clean) 保证噪声向量与信号同维度
noise = 0.3 * randn(size(x_clean));
x_noisy = x_clean + noise;  % 含噪信号 = 原始信号 + 噪声

%% 设计指标：低通，截止约 30 Hz；抽头数 M（系数长度）
fc = 30;                    % 截止频率 (Cutoff Frequency) Hz
M = 31;                     % 系数个数 (抽头数); 阶数为 M-1 = 30
nyq = fs / 2;               % 奈奎斯特频率 = 采样率/2 = 500 Hz
Wn = fc / nyq;              % fir1 用归一化截止频率 (0~1), 30/500 = 0.06

%% 方法 1：firls（分段理想幅度 + 最小二乘）
% f: 频率分段点 (归一化到 [0,1], 1 对应 Nyquist)
%    [0, fc/nyq]      : 通带 (0-0.06)
%    [fc/nyq, 1.2*fc/nyq]: 过渡带 (0.06-0.072)
%    [1.2*fc/nyq, 1]  : 阻带 (0.072-1)
% a: 对应的期望幅度
%    [1, 1] : 通带期望幅度为 1
%    [0, 0] : 阻带期望幅度为 0
% firls 在最小二乘意义下逼近这些理想幅度
f = [0, fc/nyq, 1.2*fc/nyq, 1];
a = [1, 1, 0, 0];
h_firls = firls(M-1, f, a);  % M-1 是滤波器阶数

%% 方法 2：fir1（窗函数法，汉明窗）
% fir1 是经典的窗函数法设计
% 参数说明:
%   M-1    : 滤波器阶数
%   Wn     : 归一化截止频率 (0~1)
%   'low'  : 低通滤波器
%   hamming(M): 汉明窗 (减少吉布斯现象)
% 汉明窗相比矩形窗有更好的阻带衰减,但过渡带更宽
h_fir1 = fir1(M-1, Wn, 'low', hamming(M));

%% 频响 (频率响应)
% freqz 计算数字滤波器的频率响应
% 参数: (分子系数, 分母系数, 频率点数, 采样率)
% 返回: H(复数频率响应), w(频率向量 Hz)
% FIR滤波器分母为1,因为它是全零点系统(无极点)
[H_firls, w] = freqz(h_firls, 1, 1024, fs);
H_firls_mag = 20*log10(max(abs(H_firls), 1e-12));  % 幅度响应 (dB), 1e-12避免log10(0)

[H_fir1, ~] = freqz(h_fir1, 1, 1024, fs);  % ~表示不关心第二个返回值
H_fir1_mag = 20*log10(max(abs(H_fir1), 1e-12));

%% 群延迟 (Group Delay)
% 群延迟 = -dφ/dω, 表示信号包络的延迟
% 对于线性相位FIR, 群延迟 = (M-1)/2 = 15 样点
% grpdelay 参数: (分子系数, 分母系数, 频率点数, 采样率)
gd_firls = grpdelay(h_firls, 1, 1024, fs);
gd_fir1  = grpdelay(h_fir1, 1, 1024, fs);

% 只看通带内的群延迟 (w <= fc)
idx = w <= fc;
fprintf('firls 群延迟（约，通带内中位数）: %.2f 样点\n', median(gd_firls(idx)));
fprintf('fir1  群延迟（约，通带内中位数）: %.2f 样点\n', median(gd_fir1(idx)));

%% 滤波 (应用设计好的FIR滤波器)
% filter 函数实现差分方程: y[n] = b[0]x[n] + b[1]x[n-1] + ... + b[M-1]x[n-M+1]
% 参数: (分子系数, 分母系数, 输入信号)
% FIR滤波器分母为1,因为它是全零点系统(无极点)
% 输出 y[n] 是输入信号与滤波器系数的卷积
y_firls = filter(h_firls, 1, x_noisy);  % 使用firls设计的滤波器
y_fir1  = filter(h_fir1, 1, x_noisy);   % 使用fir1设计的滤波器

%% 作图（6 子图：与说明一致）
% 创建新窗口: 名称 'FIR 学习 Demo', 位置 [x, y, width, height]
figure('Name', 'FIR 学习 Demo', 'Position', [100, 100, 1200, 800]);

%% 子图1: 原始信号 vs 含噪信号
subplot(3, 2, 1);  % 3行2列的第1个位置
plot(t, x_clean, 'b', 'LineWidth', 1.2); hold on;  % 蓝色粗线: 原始信号
plot(t, x_noisy, 'r', 'LineWidth', 0.8);        % 红色细线: 含噪信号
title('原始 vs 含噪');
xlabel('时间 / s'); ylabel('幅度');
legend('原始', '含噪', 'Location', 'best');
grid on;

%% 子图2: firls滤波器输出
subplot(3, 2, 2);
plot(t, x_clean, 'b', 'LineWidth', 1.2); hold on;
plot(t, y_firls, 'g', 'LineWidth', 1);  % 绿色: firls滤波后信号
title('firls 输出');
xlabel('时间 / s'); ylabel('幅度');
legend('原始', 'firls 后', 'Location', 'best');
grid on;

%% 子图3: fir1滤波器输出
subplot(3, 2, 3);
plot(t, x_clean, 'b', 'LineWidth', 1.2); hold on;
plot(t, y_fir1, 'm', 'LineWidth', 1);  % 品红色: fir1滤波后信号
title('fir1 输出');
xlabel('时间 / s'); ylabel('幅度');
legend('原始', 'fir1 后', 'Location', 'best');
grid on;

%% 子图4: 幅度频率响应对比
subplot(3, 2, 4);
plot(w, H_firls_mag, 'b', 'LineWidth', 1.5); hold on;
plot(w, H_fir1_mag, 'r', 'LineWidth', 1.5);
title('幅度频率响应');
xlabel('频率 / Hz'); ylabel('幅度 / dB');
legend('firls', 'fir1', 'Location', 'best');
grid on; xlim([0, 200]); ylim([-80, 5]);  % x轴限制0-200Hz, y轴限制-80到5dB

%% 子图5: 滤波器系数对比
% stem 绘制离散序列图 (火柴杆图)
subplot(3, 2, 5);
stem(0:M-1, h_firls, 'b', 'filled', 'MarkerSize', 5); hold on;
stem(0:M-1, h_fir1, 'r', 'filled', 'MarkerSize', 4);
title('系数对比');
xlabel('索引 k'); ylabel('h[k]');
```

### 9.1 运行后建议观察什么

- 频响在截止附近是否满足「10 Hz 基本通过、50/200 Hz 被压」的直觉（具体衰减与阶数、窗型、`firls` 分段有关）。
- 两法频响形状差异：过渡带宽窄、阻带波纹等。
- **群延迟**：FIR 线性相位时，信号整体会有固定延迟；若与别的处理链路对齐，要考虑对齐采样点。

## 10. 常见误区与边界

- **「噪声被有效抑制」**：本 Demo 的噪声是**白噪声**，低通不会同等抑制带内噪声；你看到的是高频分量与部分宽带噪声被削弱后的主观效果，不要概括为「低通去一切噪」。
- **`firls` 的频率向量**：必须在 $[0,1]$ 内单调非减，且首末常为 $0$ 与 $1$（对应归一化 Nyquist）；分段越细越能控制阻带，但阶数不够时仍可能达不到理想形状。
- **阶数与计算量**：$M$ 越大，卷积越长；实时系统要同时看乘法次数与延迟。
- **工具箱**：无 Signal Processing Toolbox 时，需自写卷积与窗函数法系数生成，本文 Demo 不覆盖。
